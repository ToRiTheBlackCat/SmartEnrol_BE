## 📘 Project Overview

### Description
- **SmartEnrol** is an advanced AI-based platform built to support Vietnamese high school students in navigating the complex university admission process. By analyzing student data and retrieving the latest admission policies from official university sources, SmartEnrol acts as a personalized admission method consultant.

- At its core, the system uses a Retrieval-Augmented Generation (RAG) model to combine neural language generation with dynamic information retrieval, ensuring up-to-date and context-aware recommendations for each student.
